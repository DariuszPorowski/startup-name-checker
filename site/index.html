      How it works

      Every lookup goes directly from your browser to a public service — there is no backend, nothing is stored, and nothing is tracked.

      • .com / .app — official registry RDAP (Verisign, Google Registry), falling back to rdap.org and Google Public DNS.
      • GitHub — GitHub REST API. X — X oEmbed, falling back to FxTwitter.
      • YouTube — Unavatar. TikTok — TikTok oEmbed. Facebook — Graph API (detects public Pages only; personal profiles can’t be checked).
      • Threads, LinkedIn and fallbacks — the public page is read through Jina Reader (or Microlink).
      • Instagram blocks automated lookups, so open the link to check. If the handle has a Threads profile, it’s marked taken because Threads shares Instagram usernames.
      Available

      Likely available
      No trace found, but the service can’t fully confirm it.
      Taken
      The name is already in use.
      Check manually
      The service blocks automated checks — open the link.
      Unknown
      The lookup failed or hit a rate limit — try again later.
      Not allowed
      The name breaks the platform’s username rules.

      Free services limit how often they can be used (for example GitHub: 60 lookups/hour, Unavatar: 25/day, Jina Reader: 20/minute). Results are best effort — always confirm before you commit to a name.

      No backend, no cookies, no tracking. The name you check is sent straight from your browser to the services that answer the lookups.
